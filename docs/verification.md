# 验证记录

## 已实现范围

Electron + PDF.js 桌面阅读器：本地打开、横向连续与纵向多列布局、缩放、按页／连续滚动、页面纵向居中、页码跳转、文字选择与复制基础、全文搜索、目录、密码输入、最近文件及阅读位置恢复。不包含批注编辑、PDF 编辑、多标签页。

本轮增加跨平台统一的自定义标题栏、“文件”菜单、首次启动欢迎与引导、默认自动续读。删除重复的打开文件行，空白状态不显示阅读工具栏。上次文件不可用时允许重新选择；系统或命令行明确打开的文件优先。

```bash
bun install --frozen-lockfile
bun run test
bun run build
bun run test:e2e
```

- **46 项 Vitest 单元测试通过**：安全与持久化 16 项、阅读几何与输入策略 12 项、启动／恢复与窗口 IPC 18 项。
- TypeScript 与 Vite 生产构建通过。主应用包含 PDF.js，Vite 有大包体积提示；没有忽略或隐藏该提示。
- **8 项 Playwright Electron 测试通过**。使用实际 Electron 与生产资源，无远程 PDF、无模拟渲染器；测试 PDF 是本地生成的合成数据。
- 离线资源检查包含 CMap、字体、WASM 以及已有便笺的图标。PDF.js worker 单独打包，不回退到主线程 fake worker。

## 端到端覆盖

1. 启动参数打开 PDF，真实文字层可选择；搜索及下一匹配、无结果、目录跳转；横向居中、纵向每行页数；关闭重开保留页码与缩放；沙箱内无 Node require；离线资源可读取。
2. renderer 忙碌时连续接收原生 B→A 打开事件，保留 A 刚读到的第 7 页，不被事件中的旧磁盘快照覆盖。
3. 页码改变后立即退出，最终位置在退出前写入磁盘。
4. 首次启动显示欢迎与引导；再次启动不重复展示；无文档时隐藏阅读工具栏；macOS 快捷键提示使用 ⌘。
5. 重启后自动恢复上次 PDF 与页码；手动关闭文档后不会在同一窗口立即自动重开。
6. 显式启动参数优先于上次文件，且不覆盖上次文件已保存的页码。
7. 上次文件缺失时提示错误，通过“文件”菜单重新打开；菜单支持键盘和焦点返回；自定义最小化、最大化／还原、关闭窗口及退出前保存有效。文件选择测试替代原生对话框结果，不代表已验证系统选择器手势。
8. resize 已排队、下一帧尚未运行时跳到第 7 页，刷新后仍为第 7 页，关闭保存与重开均保持第 7 页。

## 本轮发现与修复

- 空白窗口没有待写入位置时，退出重试可能仍处于原来的已取消关闭请求内，导致无法退出。将真正关闭延后到下一事件循环；首次启动后退出／重启测试验证通过。
- 首版提交 `bc5b3ae` 的远端 macOS E2E 曾发生第 7 页变回第 1 页。CI 截图表明回退发生在关闭之前。本地复现并记录到 resize 下一帧回调使用旧阅读锚点覆盖新页码：改为回调执行时读取最新锚点。正式回归测试先复现失败，再在修复后通过。
- 真实 Electron 截图检查覆盖 800×560、1440×900 的欢迎页与阅读页；标题栏、欢迎引导、文件名和窗口控件可见且无裁切。机械扫描中直接解析未构建 HTML 导致字号／颜色误报；以实际应用截图和 CSS 为准。15px 空态标语补录到设计字号中。
