# PanoPDF 首版需求

状态：用户已确认。

## 产品定位

- **名称**：PanoPDF
- **中文描述**：全景 PDF 阅读器
- **标语**：把 PDF 铺开读。
- **一句话介绍**：横向展开，连续滚动，让多页内容同屏呈现。

## 技术与平台

- 使用 Electron 构建桌面应用。
- 使用 PDF.js 解析与渲染 PDF。
- 支持 macOS、Windows、Linux。
- 使用 Bun 管理依赖与脚本；单元测试使用 Vitest，端到端测试使用 Playwright。
- 引擎选型依据见 [PDF 渲染引擎研究](research/pdf-rendering-engines.md)。

## 布局与滚动

### 横向布局

- 页面沿水平方向连续排列，不按固定页数组合。
- 同屏页数由窗口大小、页面尺寸和缩放比例决定；“同时看 3–4 页”只是使用示例，不是限制。
- 鼠标滚轮横向推进，并按页吸附。
- 触控板保留顺滑的连续滚动，不对每次微小滑动强制翻页。
- 页面低于阅读区域时纵向居中。
- 页面放大后超出阅读区域高度时，允许上下查看，保证全部内容可访问。

### 纵向布局

- 支持切换为纵向滚动。
- 可调整每行显示的页数。
- “每行页数”仅用于纵向布局，不限制横向布局的同屏页数。

## 缩放与定位

- 支持自由缩放和百分比缩放。
- 提供适应高度、容纳指定页数等快捷选项。
- 快捷选项结合显示缩放比例和容纳页数，例如“75% · 容纳 3 页”；对应比例动态计算，不将某个百分比与页数固定绑定。
- 缩放时尽量保持当前阅读位置，避免无故跳到其他页面。

## 基础阅读功能

- 打开本地 PDF。
- 页码跳转。
- 文字选择与复制。
- 全文搜索。
- 显示与导航文档目录。
- 记住阅读位置。

## 启动与窗口体验

- 使用跨平台一致的自定义顶部标题栏，显示文件名与窗口控制。
- 标题栏下不再单独设置打开文件行；通过“文件”菜单打开或关闭文档。
- 默认自动打开上次的文件，并恢复阅读位置；系统或命令行明确打开的文件优先。
- 首次启动显示欢迎界面和打开文件引导，且首次启动状态持久化。
- 上次文件不可用时提供明确错误与重新打开入口。
- 关闭文档返回空白状态，不关闭窗口，也不立即自动重新打开。

## 首版不包含

- 批注。
- PDF 编辑。
- 多标签页。

## 参考

- Skim：普通阅读器基础上的横向布局参考。
- [Scrolex](https://github.com/molecule-man/scrolex)：参考滚轮横向翻页、按页吸附，以及结合百分比和容纳页数的缩放选项。
- PanoPDF 需明确实现页面纵向居中，不照搬参考产品的布局不足。
